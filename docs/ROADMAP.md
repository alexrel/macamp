# MacAmp Roadmap

Порт WinAmp 2.9x на macOS с оригинальной эстетикой и поведением. Отмечай пункты `[x]` по мере выполнения.

## Готово
- [x] Воспроизведение MP3, AAC, WAV, AIFF, FLAC, ALAC; ID3/метаданные, CP1251
- [x] Main / Equalizer / Playlist, shade-режимы, магнитная стыковка, 2x
- [x] Скины .wsz: загрузка, переключение на лету, курсоры (свои + встроенные из winamp.exe)
- [x] 10-полосный EQ + пресеты, визуализатор (все режимы Winamp)
- [x] Плейлисты M3U/M3U8/PLS/XSPF (абсолютные, относительные, VLC), drag & drop, открытие из Finder
- [x] Интернет-радио через движок (EQ/FFT), ICY-метаданные, переподключение
- [x] Fade-out, stop after current, manual advance, глобальные хоткеи
- [x] Preferences (Setup, File types, иконки документов), Track Info, Win32-диалоги

## Не реализовано
- [ ] Ogg Vorbis: проверить декодирование (сейчас через AVPlayer-фолбэк)
- [ ] Bookmarks (закладки)
- [ ] Кроссфейд между треками
- [ ] MIDI / MOD / Audio CD / CUE
- [ ] Сохранение плейлиста с относительными путями (опция)
- [ ] Прокси для AVPlayer-фолбэка радио
- [x] Курсоры скина во всех окнах и при неактивном приложении

## Технический долг
- [x] Чтение тегов при добавлении треков ушло с главного потока (папки читаются параллельно)
- [x] Все устаревшие синхронные вызовы AVAsset заменены на async `load` — сборка без предупреждений
- [x] `PlayerCoordinator` разбит на расширения: Playback, Files, Keyboard, Menus, Windows, State
- [x] `@MainActor` на координаторе, меню, статус-баре, делегате приложения
- [x] Удалены мёртвые XCTest в `MacAmpTests/` (тесты — `./build.sh test`)
- [x] Удалены устаревшие `docs/PLAN.md`, `docs/CHECKLIST.md`, `docs/TASKS.md` (`.ai-factory/` локальная, в .gitignore)
